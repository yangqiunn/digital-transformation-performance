# 数字化转型对企业经营绩效的影响研究

> 基于中国 A 股制造业上市公司的实证分析 —— 三周完成一篇预演毕业论文

本项目是一份完整的**实证研究复现包**，包含论文全文、可复现代码、面板数据与结果文件，
遵循"数据加载 → 数据清洗 → 变量构建 → 信效度检验 → 回归分析"五步流水线。

## 研究设计

| 要素 | 说明 |
|------|------|
| 样本 | 300 家制造业上市公司 × 2019—2023 年 = 1500 个企业-年份观测 |
| 被解释变量 | ROA（总资产收益率）= 净利润 / 总资产 |
| 核心解释变量 | DT_index（数字化转型指数，年报词频法取对数）|
| 测度交叉验证 | DT1—DT5 五题项 Likert 量表（1—7）|
| 控制变量 | size（企业规模）、lev（资产负债率）、age（企业年龄）、rd（研发投入强度）|
| 模型 | OLS 多元回归，DT 与 size 中心化处理 |

## 主要发现

| 变量 | 系数 | 显著性 | 解读 |
|------|------|--------|------|
| DT_c | **0.0172** | *** (p&lt;0.01) | 数字化每提高 1 个标准差，ROA 上升约 **1.24 个百分点** |
| size_c | 0.0131 | *** | 规模越大绩效越好（规模经济） |
| lev | **-0.0388** | *** | **财务杠杆显著抑制绩效**（负向边界条件）|
| age | 0.0011 | *** | 经营年限越长绩效越优 |
| rd | 0.0770 | ** | 研发投入正向促进绩效 |

- 模型拟合：**R² = 0.6016**，调整后 R² = 0.6002
- 信度检验：**Cronbach's α = 0.606**，KMO = 0.531（可接受水平）

## 核心结论

1. **数字化转型显著提升企业经营绩效**，且该效应通过词频法与量表法双重测度验证，结论稳健。
2. **财务杠杆构成负向边界条件** —— 高杠杆企业的偿债压力会挤占数字化投入的现金流，削弱转型收益。
3. **数字化转型量表 α = 0.606**，达到社会科学研究可接受标准，但距优良标准仍有优化空间，
   提示单一维度量表难以完整捕捉多维构念，未来可开发多维量表。
