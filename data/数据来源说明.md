# 数据来源与处理说明

## 一、数据文件清单

| 文件名 | 内容 | 来源 | 处理步骤 |
|--------|------|------|----------|
| `data/panel_data.csv` | 企业-年份面板数据（1500 条观测，300 家制造业上市公司 × 2019-2023 年） | 模拟生成（种子=42，可复现） | 由 `code/pipeline.py` 的 `step1_load()` 生成；实际研究中替换为 CSMAR/Wind 导出数据 |
| `results/descriptive.csv` | 描述性统计 | 由面板数据计算 | `step5_regression()` 输出 |
| `results/correlation.csv` | 相关系数矩阵 | 由面板数据计算 | `step5_regression()` 输出 |
| `results/reliability.csv` | 信度检验（CITC/α） | 由问卷题项计算 | `step4_reliability()` 输出 |
| `results/reliability_summary.txt` | Cronbach's α 与 KMO | 由问卷题项计算 | `step4_reliability()` 输出 |
| `results/regression.csv` | 回归结果 | 由面板数据计算 | `step5_regression()` 输出 |
| `results/summary.txt` | R²、样本量摘要 | 由回归计算 | `step5_regression()` 输出 |

## 二、变量说明

| 变量 | 含义 | 测量方式 |
|------|------|----------|
| `DT_index` | 数字化转型指数 | 年报关键词词频取对数 |
| `DT1`-`DT5` | 数字化转型感知量表 | 5 题项，1-7 Likert 量表 |
| `ROA` | 总资产收益率 | 净利润 / 总资产 |
| `size` | 企业规模 | 总资产自然对数 |
| `lev` | 资产负债率 | 总负债 / 总资产 |
| `age` | 企业年龄 | 观测年份 - 成立年份 |
| `rd` | 研发投入强度 | 研发支出 / 营业收入 |

## 三、处理步骤（对应五步流水线）

1. **数据加载**：读取/生成企业-年份面板数据。
2. **数据清洗**：对连续变量做 1%/99% 缩尾（Winsorize）处理，剔除缺失值。
3. **变量构建**：量表题项取均值得到 `DT_scale`；对 `DT_index`、`size` 做中心化处理。
4. **信效度检验**：计算 Cronbach's α、CITC、KMO。
5. **回归分析**：OLS 多元回归，输出系数、标准误、t 值、p 值、R²。

## 四、可复现性说明

- 随机种子固定为 42，重复运行 `python3 code/pipeline.py` 可得到完全一致的结果。
- 依赖：`numpy`, `pandas`, `scipy`（见 `requirements.txt`）。
- 运行命令：`python3 code/pipeline.py`
